# Getting help

## Questions

Ask in the [TEDI Slack](https://join.slack.com/t/tedisystem/shared_invite/zt-3hd8tnjf7-Z1smXI~ns0p8E2cxoFUKbQ). There are channels for React, Angular and design.

For documentation, see [tedi.ee](https://www.tedi.ee/) (design guidelines and component documentation), [Storybook](https://storybook.tedi.ee/) (component usage and API) and the [developer wiki](https://github.com/TEDI-Design-System/general/wiki).

## Feature requests and new components

Propose new components and improvements in [Discussions](https://github.com/TEDI-Design-System/general/discussions).

## Bugs

Open an issue in the repository it concerns:

| Topic                                        | Repository                                                      |
| -------------------------------------------- | --------------------------------------------------------------- |
| React components                             | [react](https://github.com/TEDI-Design-System/react/issues)     |
| Angular components                           | [angular](https://github.com/TEDI-Design-System/angular/issues) |
| Design tokens and shared styles              | [core](https://github.com/TEDI-Design-System/core/issues)       |
| Design or UX problems in existing components | [design](https://github.com/TEDI-Design-System/design/issues)   |

## Security

See the [security policy](https://github.com/TEDI-Design-System/.github/blob/main/SECURITY.md). Do not report vulnerabilities in public issues.

## Other

Email [info@tedi.ee](mailto:info@tedi.ee).
