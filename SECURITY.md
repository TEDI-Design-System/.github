# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, discussions or Slack.

Report them privately through the **Security** tab of the affected repository, under **Report a vulnerability**:

- [react](https://github.com/TEDI-Design-System/react/security/advisories/new)
- [angular](https://github.com/TEDI-Design-System/angular/security/advisories/new)
- [core](https://github.com/TEDI-Design-System/core/security/advisories/new)

If you can't use GitHub, email [info@tedi.ee](mailto:info@tedi.ee).

Include as much of the following as you can:

- affected package and version
- description of the vulnerability and its impact
- steps to reproduce or a proof of concept
- a suggested fix, if you have one

## What happens next

The TEDI team confirms receipt, investigates and keeps you updated. The fix is prepared privately and released as a new package version. A security advisory is then published on GitHub, which reaches consumers through `npm audit` and Dependabot.

## Supported versions

Security fixes are made to the versions listed in [Supported versions](https://github.com/TEDI-Design-System/general/wiki/Supported-versions).
