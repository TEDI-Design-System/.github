# Contributing to TEDI

Thanks for helping improve the TEDI Design System. Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

- **Code:** each library has its own contributing guide with setup and workflow: [react](https://github.com/TEDI-Design-System/react/blob/rc/CONTRIBUTING.md), [angular](https://github.com/TEDI-Design-System/angular/blob/rc/CONTRIBUTING.md).
- **New components and feature ideas:** propose them in [Discussions](https://github.com/TEDI-Design-System/general/discussions).
- **Design problems:** report design or UX problems in existing components in the [design](https://github.com/TEDI-Design-System/design/issues) repository.
- **Process:** component tiers, Definition of Done, Gitflow, commit convention and releases are in the [developer wiki](https://github.com/TEDI-Design-System/general/wiki).

Before starting larger work, open an issue so the change can be discussed first. For questions, see [Getting help](SUPPORT.md).
